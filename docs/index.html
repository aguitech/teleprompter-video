PASO 03

API del backend PHP

Backend standalone con SQLite. Procesa cada escena con FFmpeg+GD y devuelve MP4 con chroma aplicado.

POST

/api/sessions.php

Crea o actualiza una sesión con N guiones. Retorna session_id.

POST /api/sessions.php
Content-Type: application/json

{
  "id": "opcional",
  "title": "Promo Q4",
  "brand": "afore",
  "chroma_color": "#00ff00",
  "tolerance": 80,
  "bg_mode": "transparent",
  "scenes": [
    { "numero": 1, "texto": "..." },
    { "numero": 2, "texto": "..." }
  ]
}
GET

/api/sessions.php

Lista todas las sesiones, o detalle con escenas si pasas ?id=X.

GET /api/sessions.php
GET /api/sessions.php?id=sess_xxx

Response: { ok, sessions: [...] }
         o { ok, session: {...}, scenes: [...] }
POST

/api/process.php

Procesa UNA escena: recibe WebM, aplica chroma, devuelve MP4.

POST /api/process.php
Content-Type: multipart/form-data

Fields:
  session_id: sess_xxx
  numero_escena: 1
  video: File (WebM)

Response: {
  ok, scene_id, frames, duration,
  chroma_hits, output_url
}
POST

/api/concat.php

Une todas las escenas procesadas en un MP4 final.

POST /api/concat.php
Content-Type: application/json

{ "session_id": "sess_xxx" }

Response: {
  ok, final_url,
  duration, scenes_count
}
GET

/api/download.php

Descarga MP4 procesado de una escena o video final concatenado.

GET /api/download.php?session=X&scene=N
GET /api/download.php?session=X&final=1

→ video/mp4 stream
GET

/api/frames.php

Lista frames PNG/JPG extraídos de una escena (debug).

GET /api/frames.php?session=X&scene=N

Response: {
  ok, frames: [
    "frames_001.jpg",
    "frames_002.jpg",
    ...
  ]
}
DELETE

/api/sessions.php?id=...

Elimina una sesión completa (BD + filesystem).

DELETE /api/sessions.php?id=sess_xxx

Response: { ok, deleted: "sess_xxx" }
PASO 04

Stack técnico

100% código abierto. Sin servicios externos. Backend standalone PHP + SQLite.

🛠️ Componentes del sistema

  • Frontend Vanilla JS + HTML5 · MediaRecorder API · Canvas API
  • Teleprompter Scroll programático con contador de palabras y velocidad
  • Greenscreen MediaRecorder con video/webm codec VP8/VP9
  • Backend PHP 8.3 + extensión GD para manipulación pixel a pixel
  • Frames FFmpeg extrae 24fps JPEG, GD aplica chroma, PHP recompone
  • Encoding FFmpeg H.264 + AAC con libx264 rápido
  • Persistencia SQLite 3 (zero config) en storage/db/
  • Storage Filesystem organizado por sesión y escena
  • CORS Habilitado para acceso desde GitHub Pages
  • Deploy Frontend en GitHub Pages · Backend en servidor PHP

📐 Chroma key

Algoritmo de distancia euclidiana en espacio RGB. Cada pixel se compara con el color clave; si la distancia es menor que la tolerancia, se reemplaza por el fondo seleccionado (transparente, color sólido, o sin reemplazo).

dist = sqrt((r-kr)² + (g-kg)² + (b-kb)²)
if dist < tolerance: pixel = bg

🎬 FFmpeg pipeline

Pipeline de 3 pasos: extract → process → encode. Mantiene calidad y resolución original del video grabado.

1. ffmpeg -i input.webm -q:v 2 frames/%04d.jpg
2. GD: chroma key por pixel
3. ffmpeg -framerate 24 -i processed/%04d.jpg
   -c:v libx264 -pix_fmt yuv420p output.mp4

🗄️ SQLite schema

Dos tablas: sesiones (metadata) y escenas (texto + status). Cada escena referencia su sesión con foreign key.

CREATE TABLE sesiones (
  id TEXT PRIMARY KEY,
  title TEXT, brand TEXT,
  chroma_color TEXT, tolerance INT,
  bg_mode TEXT, created_at TEXT
);
CREATE TABLE escenas (
  id INTEGER PRIMARY KEY,
  session_id TEXT,
  numero INT, texto TEXT,
  status TEXT, frames INT,
  duration REAL, output_url TEXT
);
