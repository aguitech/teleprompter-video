PASO 03

Post-producción automática en PHP

El backend recibe tu video, extrae frames con FFmpeg, aplica chroma key pixel por pixel, y recompone el video final.

A

Recepción

Subes el WebM → el servidor lo guarda con un session_id único.

B

Extracción

FFmpeg extrae frames a 24fps como PNGs numerados.

C

Chroma key

PHP con GD lee cada PNG, aplica threshold al verde, marca alpha=0 en píxeles match.

D

Recompone

FFmpeg recombina los PNGs modificados en MP4 con audio original.

📡 Endpoint PHP

POST /api/process.php
Content-Type: multipart/form-data

Fields:
  video:        File WebM grabado
  chroma_color: #00ff00 (hex)
  tolerance:    40 (0-120)
  bg_color:     #003D7A (hex, opcional)
  title:        "Promo Afore Q4"
  brand:        "afore" | "bancoppel" | "ambas"

Response:
  { ok: true, session_id, frames, duration, output_url }

🛠️ Stack del backend

  • PHP 8+ con GD para manipulación pixel a pixel
  • FFmpeg para extracción de frames y reencoding
  • MySQL/SQLite para sesiones, escenas y resultados
  • Almacenamiento local en storage/sessions/{id}/
