PASO 03

API del backend PHP

Backend standalone con SQLite. Procesa cada escena con FFmpeg+GD y devuelve MP4.

POST

/api/sessions.php

Crea o actualiza una sesión con N guiones.

POST /api/sessions.php
Content-Type: application/json

{
  "id": "opcional (regenera)",
  "title": "Promo Q4",
  "brand": "afore",
  "chroma_color": "#00ff00",
  "tolerance": 80,
  "bg_mode": "transparent",
  "scenes": [
    { "numero": 1, "texto": "..." },
    { "numero": 2, "texto": "..." }
  ]
}
GET

/api/sessions.php

Lista todas las sesiones o una específica con sus escenas.

GET /api/sessions.php
GET /api/sessions.php?id=sess_xxx

Response: { sessions: [...] }
POST

/api/process.php

Procesa UNA escena: recibe WebM, aplica chroma, devuelve MP4.

POST /api/process.php
Content-Type: multipart/form-data

Fields:
  session_id: sess_xxx
  numero_escena: 1
  video: File (WebM)

Response: { ok, scene_id, frames, duration, output_url }
POST

/api/process_batch.php

Procesa TODAS las escenas pendientes de una sesión en una sola llamada.

POST /api/process_batch.php
Content-Type: application/json

{ "session_id": "sess_xxx" }

Response: {
  ok: true,
  processed: [ { escena: 1, ok: true, output_url }, ... ],
  pending: 0
}
POST

/api/concat.php

Une todas las escenas procesadas en un solo MP4 final.

POST /api/concat.php
Content-Type: application/json

{ "session_id": "sess_xxx" }

Response: { ok, final_url, duration, scenes_count }
GET

/api/download.php?id=...

Descarga MP4 procesado de una escena o video final concatenado.

DELETE

/api/sessions.php?id=...

Elimina una sesión completa (con todas sus escenas y archivos).

🛠️ Stack del backend

  • PHP 8+ con extensión GD para manipulación pixel a pixel
  • FFmpeg para extracción de frames (24fps) y reencoding H.264
  • SQLite 3 para persistir sesiones y escenas (zero config)
  • Almacenamiento en filesystem bajo storage/sessions/<id>/
  • CORS habilitado para acceso desde GitHub Pages
